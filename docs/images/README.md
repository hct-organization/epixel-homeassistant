# Images

Drop the files below in here and the main README picks them up automatically.
No other change is needed.

| File | What it should show | Suggested size |
|---|---|---|
| `hero.png` | The display on a wall or desk, showing a Home Assistant page | 1280 × 720 |
| `pairing.png` | The 4-digit code screen on the display | 480 × 720 |
| `page-builder.png` | Home Assistant's "Add page" form with entities selected | 900 × 600 |
| `device-page.jpg` | Close photo of the screen with 4 or 6 boxes | 800 × 1200 |
| `device.jpg` | Product shot of the display on a neutral background | 800 × 800 |

Keep each file under about 1 MB so the page stays fast. A short product video is
better hosted on YouTube and linked from the README than committed here.
